## 使用与边界

点击聊天顶部的联系人进入设置；群聊顶部打开群信息，再点成员设置。保存目标后可立即运行；定时默认关闭，需要明确启用。应用退出或 Mac 休眠时不会后台执行。暂停只停止后续调度和未发送排队任务，已提交工作通过原记录核查。固定远端计划和本机自主续跑按实际适配能力区分；跨 Agent 派工留待后续。

发现页面只读取自己 Mac 已安装/已保存的连接。已检查可用与“已保存连接，发送时核对”分别显示，不宣称服务账号或远端会话隔离已经验证。MCP 本身是工具连接，新的消息必须先明确选择聊天助手；已有执行快照和精确工具批准保留。真实 Muse/Grok/Dots/Cue 的长期账号稳定性、真实系统休眠/唤醒、VoiceOver、签名公证不由本轮合成检查证明。
