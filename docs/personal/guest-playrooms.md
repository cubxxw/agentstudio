# 来房间玩：把自己的 Agent 邀请给朋友

在 Mac 左侧点星光按钮，选一个玩法。朋友打开 HTTPS 邀请，填昵称并点「进来一起玩」即可参与，不需要 AgentRoom 账号。昵称只是房间身份，并非实名验证。接受后可以看到本房间已有的共同消息和计划。

## 三种开场

| 玩法 | 可以一起做什么 |
| --- | --- |
| 小熊会客厅 | 给 AI 分身写一段公开性格，和朋友破冰、交换点子；分身明确表明 AI 身份，不代主人承诺 |
| 下一站，去山那边 | 投票选山间、海边或城市，补齐预算、忌口、时间和分工，保存旅行笔记 |
| 一起造点东西 | 讨论一个小项目，共同勾清单、编辑创作便笺，再下载实际保存的 Markdown |

案例的背景和性格都可以改。这里只做讨论和共同计划；访客 Agent 不执行程序、预订、付款、发邮件或部署网站。

## 主人怎么邀请

1. 选本机 Codex 或 Pi，编辑房间名称、主人昵称、共同背景和分身说明。只有这些公开内容和本房间讨论进入访客 Agent。可主动把当前聊天最近八条文本带入编辑框，检查后再发布。
2. 创建后点「开启网页邀请」。本机需要 `~/.local/bin/cloudflared`；系统只将独立的访客监听器接入临时 HTTPS 通道，不公开个人工作区接口。
3. 复制邀请给朋友。另一个「本机预览」地址只适用于这台 Mac，不能当成公网邀请。
4. 主人也可以参与聊天和计划。移除访客会撤销其会话并更换邀请，旧链接不能重新入场；其他已加入的朋友继续使用。关闭房间使邀请及已有访客会话失效。

邀请是持有者可使用的能力，转发链接的人也能邀请别人。默认 24 小时、5 位访客、全房间 30 次 Agent 调用；服务允许的最大值为 72 小时、10 位访客和 30 次调用。每条消息最多 4000 字，共同笔记和回复最多 12000 字。主人离线、Mac 休眠或应用退出时不承诺服务可用。

## 共同编辑与恢复

投票和清单同步给房间成员。笔记编辑期间轮询不会覆盖未保存草稿；别人先保存时会提示冲突，保留自己的输入，由你选择是否载入新版本。网络暂时断开会暂停操作并重连；刷新后使用房间 Cookie 恢复身份。

模型请求按接受时的房间背景和执行配置固定，重复提交同一请求不会再跑一遍。服务中断后排队请求标为失败、在途请求标为待核查，均不自动重发。停止未确认时，相同后端的访客队列等候；主人必须核查原执行已停止，再明确解除待核查状态。关闭或到期房间仍可处理这项核查，不能重新公开旧输出。

## 边界

访客只能访问这个房间的共同背景、成员、消息、投票、清单和笔记。不会自动共享原私聊、联系人私密指令、个人记忆、文件、CLI 配置或第三方账号。模型仅有本房间只读工具；不能建立受限执行时直接失败，不退回普通工具权限。房间发布前应检查主动带入的文本。

邀请随机值加密保存在工作区 vault；会话在服务端只存摘要。邀请放在 URL fragment，加入后从地址栏移除。HTTPS 下的会话 Cookie 带 Secure、HttpOnly、SameSite=Strict；房间、身份、移除和到期每次访问都检查。SQLite 聊天和计划本身不做端到端或整库加密。

网页邀请使用 [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)，地址临时、无持续可用保证。当前使用轮询，不依赖 SSE。重新开启通道可能需要重发新地址；内容和已有身份保存在本机。通道显示在线表示地址已签发，不能替代实际外网连通或模型验收。

## 开发验收

后端覆盖接受、跨房间隔离、重复请求、配额、版本冲突、移除、到期、关闭中执行、未知停止和重启。`dev/playrooms-acceptance.mjs` 验证三个场景的双访客、390px/1280px 布局、断线和编辑恢复。`dev/playrooms-native-acceptance.mjs` 验证实际 Electron IPC、系统剪贴板与访客端；默认合成 CLI，`--real` 使用本机已配置 Codex，`--public` 使用真实临时 HTTPS。必须通过 `AGENTROOM_EVIDENCE_DIR` 指向受管产物目录；证据不提交邀请随机值或私人聊天。
