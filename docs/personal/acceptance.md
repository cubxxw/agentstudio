## 视觉、阅读与恢复

1440px 和 390px 已检查空态、中文长文、中英混排、表格、代码和独立阅读视图。报告正文实测 17px / 33.15px、桌面约 680px 宽；窄屏宽表格/代码在自身区域滚动，不撑出整页。键盘可到达阅读控件、表格和代码区域，Escape 返回触发位置；减少动态效果的已检查元素实际无动画/过渡。最终自动回归另覆盖决定、离线和历史搜索，见[桌面阅读](evidence/qa-reader-desktop.png)、[窄屏阅读](evidence/qa-reader-narrow.png)、[决定](evidence/qa-decision.png)、[离线](evidence/qa-offline.png)、[历史搜索](evidence/qa-history-search.png)。

**原生浏览器 200% 缩放未验证。** 仅检查 720×500 CSS 视口的等效重排，不能将其写为原生 200% 通过。VoiceOver、真实中文输入法、触屏/软键盘与系统动态字号未由合成键盘事件或截图证明。

独立审查首先发现本地体验后执行模式重置、多份成果难辨认、发送过程中丢未发草稿，以及重试时上下文改变导致同 clientId 冲突。问题已分别修复，草稿/重试取得独立 5 项复核；模式保留已有修复后浏览器证据，成果补充“第 n 份 + 时间”。早期问题、工具夹具错误与之后通过保留为不同状态，没有把重跑或续接写成原本首轮通过。

实际报告来源预览还发现嵌套对话框的 Escape 会同时关闭来源与底层阅读器；已修复取消事件冒泡，最终 22 项回归及实际成果浏览器检查通过。前两次实际截图因该产品问题中止，不计为通过或夹具偶发。

## 运行与凭据合同

运行中补充形成持久队列，每个 run 的上下文截至自己的消息；早先排队的执行不读未来消息和附件。新要求让未批准的旧预览失效。unknown 外部结果挡住后续队列，重启不重发可能已提交的写入；有 A2A taskId 时查询原任务，没有稳定核查标识时保留人工查原系统的边界。决定、投递、执行、保存和外部核验分别记录。

Bearer 是可选的本机 **AES-256-GCM 文件 vault**，不是 Keychain 或远端账号证明。同 URL 不同 token 分属不同连接，确认绑定私有凭据身份，公开 `identityVerified` 保持 false；token 不进入模型目录、公开返回或持久报告，服务回显先去敏。密钥/凭据 0600、目录 0700；删除最后一个安全连接后仍保留原 key。缺失/损坏 key 保留密文、任务及原 taskId，不覆盖生成新 key；恢复原 key 并重启后核查渠道可继续。

当前没有 OAuth、自定义认证头、多用户登录、跨设备同步或公网服务部署。原 Electron/Expo/Go/Matrix 运行、原生打包安装、真实私人第三方账号、长期在线可用性及生产部署不能从这些检查推出。本地服务停止/休眠期间也不承诺继续。

独立审查的原始报告、快照、负对照和 TAP 保存在本机任务产物目录；含私人会话的 Raft 参考截图不进入仓库。对外文档只保留公开/合成证据。研究和验收过程中的工具切换、等待与恢复观察见[设计裁决](design.md)；源码机制与实际运行分开记录，见[Raft 观察](research/raft-observation.md)。
