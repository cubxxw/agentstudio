# 将个人工作间接回原有 Mac 应用

2026-11-10 · 用户纠正后修订。独立 Web 路线过早将共享产品体验定为白底绿色，偏离了目标仓库已有 macOS 设计。个人任务模型可以保留；实际交付入口应重新落回原生窗口。

## 保留什么

保留 `docs/design.md` v0.2 的 porch light：蓝暮色背景、navy 文本、indigo 操作、amber 只表示需要本人处理；SF / PingFang 为正文，Bricolage 只承担有限展示字阶。保留 Electron hiddenInset、traffic lights、窗口拖拽、Mac 菜单和关窗隐藏行为。原 Matrix / Expo / Go 源码及连接器通过显式旧模式继续存在。

保留个人执行内核的会话、排队、版本化决定、成果文件与哈希、显式记忆、MCP/A2A 连接机制。新原生模式用单独 preload 和自有 utility 承载它；不把旧网页 URL 装入远程窗口，也不把既有 Matrix token 当作新产品登录。

## 简化什么

启动默认直接输入，无需先启动 Matrix 服务或选择执行者。72px rail 只放高频入口；事情列表保留连续性，待处理是同一列表的过滤。桌面背景用于整个工作间，正文与结果用字阶和留白组织。长文按需进入阅读视图，正文 17px / 1.95 行高；宽表和代码自行滚动，读取来源后回到原位置。

同一 UI 和任务内核支持辅助 Web 开发验收；Mac 文档使用独立样式入口，避免旧客户端全局 CSS 与个人界面混合。这里的代价是视觉行为需在两个宿主验证，不能拿 Web 截图替代系统窗口。

## 控制与证据

渲染器只获固定 API 能力，没有 Node、旧 token bridge、任意 URL 或 HTTP。任务由后台推进，界面订阅变化；关窗隐藏继续，退出停止自有后台，未确认的写入先核查。收到决定、发送动作、执行与成果核验仍分开记录。

本地包不需要宿主另装 Node；它使用 Electron utility 内置的 Node / SQLite。仅本地 ad-hoc 签名，不自动发现证书或发布。现有本机 CLI 配置仍是实际执行与账号边界，文件 vault 也不包装成 Keychain。

具体窗口与任务证据见 [macOS 验收](macos-acceptance.md)。这个方向优先减少开始、监督与恢复成本；没有为“完整”追加联系人类型或新的顶层模块。
