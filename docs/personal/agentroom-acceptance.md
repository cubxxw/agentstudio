# AgentRoom 改名与测试模式验收

## 实现与兼容

显示品牌统一为 AgentRoom，新增空白工作区欢迎页和「设置 → 测试与引导」。已有工作区直接沿用，重新查看引导保留资料。独立测试模式轮换完整 profile，再回到原工作区；不会删除原账户、外部 CLI 登录或旧测试资料。

保留现有 safeStorage 内部名、普通资料目录、bundle ID、协议 URL/header、包名和 IPC。同步了本轮开发期间合并的 GET-492（主分支 160d517），保留其头像、消息呈现和侧栏布局。

## 独立审查与修复

设计审查要求冻结新写入与自动调度后核查完整运行账本，并确认 utility 真正退出；原生服务中未完成任务、未结束登录和恢复/核查失败也阻止切换。实现了这些门禁，没有 HTTP 重置接口，也不接受 renderer 提供的路径。

独立代码审查发现两项问题，均已修复：

- P1：旧 native 验收继承新的 `AGENTROOM_*` 目录变量，会覆盖其临时路径。现统一使用纯环境清理 helper，另保护 Matrix smoke 环境；用假路径组成实际 profile 解析器的回归测试证明无法落入继承目录。
- P2：测试标记会随侧栏隐藏，合并期间也可能丢失。现使用独立持续标记并保留原生测试窗口标题；原生验收覆盖收起列表、断连和设置流程。

现有聊天验收还发现首次欢迎页遮住了已连接助手的快捷入口；现保留快捷聊天，并在开始时保存引导状态。
