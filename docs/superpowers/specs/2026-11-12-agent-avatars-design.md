# AgentRoom agent avatars

Give role contacts a recognizable, persistent identity with a unified Bottts robot style, locally rendered with pinned DiceBear 9.4.2. No avatar service requests. Never use a name initial as an agent fallback. Keep AgentRoom branding, existing explicit icons and real provider bot images; discovered vendor contacts retain their provider mark until explicitly customized.

The editor offers a large preview, four deterministic candidates, five role palettes (research blue, creative violet, execution orange, collaboration teal, conversation rose), eyes/mouth/head accessories, regeneration and a status preview. Store version, style, seed and whitelisted appearance parameters with the contact and accepted run identity. Name/backend edits and discovery must never regenerate an accepted avatar. Agents may propose the same parameters during role onboarding; validation and adoption share the same contract.

Considered remote DiceBear URLs (simple but break offline/CSP and disclose seeds), Boring Avatars (restrained but less expressive) and local Bottts (chosen: consistent, recognizable, offline). Pinning the generator keeps saved identities reproducible.

True run state drives animation: queued waits quietly; running thinking breathes, other execution or verification uses an orbit; pending input asks with an amber pulse; completion has one finite green confirmation; failed/unknown/unconfirmed stop stays still with an attention marker. Idle stays still. No fake percentages or tools inferred from model text. Historical messages retain their accepted avatar and do not animate as current work. Offscreen/hidden document motion pauses, prefers-reduced-motion and an explicit per-avatar motion switch disable motion while preserving state information.

Use existing SF system typography and neutral app surfaces. Robot palette bases: blue #527fce, violet #9272c4, orange #c9833e, teal #388d83, rose #bf6f91. Squircle portraits and thin state strokes carry the visual identity; surrounding UI stays quiet. CSS compositor animation, memoized local SVG data URLs, no per-frame JS.

Verify schema rejection, stable rename/restart/snapshots, live state priority and uncertainty, role adoption, editor persistence, offline images, reduced motion, responsive layout and isolated packaged Electron. Independent review and latest CI precede merge. User authorized autonomous design/implementation in this request and AGENTS.md.
